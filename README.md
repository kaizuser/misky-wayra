# Misky Wayra

Sitio de las cabañas Misky Wayra y Sumac Mayu, en Capilla del Monte, Córdoba.
Astro 7, sitio estático, CSS propio.

```sh
npm install
npm run build             # genera dist/
npx astro preview --port 4322
npm run check             # chequeo de tipos
```

Vista previa publicada: https://kaizuser.github.io/misky-wayra/ (se actualiza con cada push a `master`).

Todo lo decidido (concepto, diseño, estructura, fotos, pendientes) está en [CLAUDE.md](CLAUDE.md).
